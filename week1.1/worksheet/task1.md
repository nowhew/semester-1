# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | lists the contents of the current location |
|     cd directory_name       | changes the current location to directory_name. can be a relative path |
|     cd ..                   | changes the current location to the parent directory of the current location|
|     cd -                    | prints the current location |
|     mkdir directory_name    | makes a directory with the name directory_name |
|     touch filename          | creates a new file with name filename |
|     git status              | shows all current uncommited changes to the local branch as well as all untracked files |
|     git add -A              | adds all files to the list of tracked files|
|     git commit -m ""        | commits all changes to the local branch with commit message -m |
|     git push                | pushes all changes to the local branch to the master branch |
|     git pull                | pulls all changes from the master branch to the local branch|
